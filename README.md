# ☕ Sip & Fresh — Qəhvə və Təbii Şirə Menyusu (Demo Layihə)

Bu layihə Veb Proqramlaşdırma dərsi üçün hazırlanmış interaktiv menyu və sifariş simulyasiyası saytıdır. Layihədə real ödəniş sistemi yoxdur, yalnız istifadəçi interfeysi (UI) və frontend məntiqi nümayiş olunur.

## 🌟 Layihənin Özəllikləri
- 🍹 **Təbii Şirələr (Soklar) və Qəhvələr:** Kateqoriyalar üzrə menyu seçimi.
- 🛒 **Səbət Sistemi:** Məhsulları səbətə əlavə etmək, sayını artırmaq/azaltmaq.
- 🧮 **Canlı Qiymət Hesablama:** Seçilən içkilərə görə yekun məbləğin avtomatik hesablanması.
- 📱 **Mobilə Uyğun (Responsive):** Həm telefon, həm də kompüter ekranlarına uyğun dizayn.
